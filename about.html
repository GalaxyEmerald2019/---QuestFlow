Project Overview

Why this platform idea matters

QuestFlow is based on a practical problem: players often manage wishlists, owned games, and price tracking in separate places. This project proposes one cleaner system for discovery, comparison, and organization.

The site was built with semantic HTML and one shared CSS file. It uses flexbox for navigation, grid for content layout, hover transitions, focus states, and a skip link for better keyboard accessibility.

Core platform ideas

Unified dashboard

A single place for owned games, tracked titles, and recommended deals.

Store integration

Support for comparing data from major stores without making the interface confusing.

User control

Filters, sorting, and clear status indicators that help users act fast.

Accessibility and design choices

The visual style uses strong contrast, readable spacing, consistent navigation, and simple card components. Images include alternative text, interactive elements have visible focus styling, and the layout remains clean on different screen sizes.

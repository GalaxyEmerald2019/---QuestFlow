One place to manage games, compare prices, and track your library.

QuestFlow is a platform concept for players who want a cleaner way to find game deals, follow releases, and keep their libraries organized across multiple stores.

Explore catalog Learn more

Price comparison

The platform collects store offers into one interface so the user can compare prices faster and avoid manually checking many websites.

Library overview

QuestFlow is designed to show owned, wishlisted, and tracked games in one organized dashboard with filters and clear status labels.

Deal alerts

The goal is to notify users about discounts, release windows, and updates in a simple format that does not overload the screen.

Built around clarity and accessibility

This project focuses on readable typography, visible focus states, keyboard-friendly navigation, and responsive layout choices. The site also uses grid, flexbox, hover effects, and a skip link to improve usability.

  • Simple navigation that works on all three pages
  • Consistent spacing and card layout using the box model
  • Responsive sections that adapt to different screen widths
